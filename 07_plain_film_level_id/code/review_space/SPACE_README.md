# Vertebra level review

A reading tool for a spine-imaging study. Reviewers are shown a radiograph with its vertebrae boxed and
named by a model, and correct the name of the lowest vertebra; two reviewers read every film independently.

**This Space contains no model, no weights and no naming algorithm** - only a form over a manifest. The
films, their names and every decision live in private dataset repositories the Space reads with its own
token, and the page is gated by a passcode. Access is by arrangement; there is nothing here to run without
it.
