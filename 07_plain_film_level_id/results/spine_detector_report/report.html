The problem the design solves

Public spine-radiograph datasets each annotate a different stretch of the column: one covers the cervical spine, another L1–L5, another T1–L5. Train per-level classes on their union and level identity becomes confounded with the dataset it came from — a class that appears in exactly one source can be predicted from scanner style rather than anatomy.

So the detector carries one class. Every vertebral body is the same object, and anatomical level is left to a second head that shares the backbone, trained later and measured separately. That leaves one hazard, and it is the reason this project exists: in a cervical-only dataset the thoracic vertebrae at the bottom of the film are real vertebrae with no ground truth, and training them as background teaches the model to suppress true positives.

Not yet in this run. The ignore-region loss mask is written (src/ignore.py) but the trained model below used cropping only. The headline numbers are therefore in-distribution, and the union-with-ignore ablation — the experiment that justifies the method — has not been run.

Two parsing bugs the validators caught. BUU's edge lines pair step-2, not consecutively — walking consecutive pairs emits a quadrilateral for every disc space as well as every body. And Roboflow exports the same image into train/valid/test under different hashes, which duplicated 107 instances and would have put one physical radiograph on both sides of a split.

Training

YOLO11m-pose, one class, four keypoints, 1024 px, AdamW, 111 epochs on one H200. Horizontal flip is disabled: on a lateral radiograph a flip is anatomically impossible and silently swaps the anterior/posterior meaning of the corner slots — there is no error, the keypoint head simply fails to converge.

Recall is not reported globally, by design. On partially-labelled sources a “missed” vertebra may be one the dataset never annotated. Detections are scored only inside the trusted-background region; outside it they are neither credited nor penalised.

The spread is small — 0.861 on BUU against 0.970 on NHANES — but BUU contributes only 15 test instances here, so that gap is not yet a measurement. None of these are cross-site. Every test image comes from a source the model also trained on.

What is not done

The specification asks for considerably more than this run delivers. Stating the gap precisely is more useful than a number that implies otherwise.

Blocked on credentials, not on work. VinDr-SpineXR requires a personal PhysioNet credentialed account — CITI training plus supervisor attestation, typically weeks. IEEE DataPort's 236 lateral full-spine films need a subscription login; those are the intended primary evaluation hold-out, so until they exist there is no genuinely external test set.

Datasets not obtained

  • CSXA — the metadata repository and its pixel-scale table are downloaded, but the 4,963 images sit behind a SciDB browser session; four candidate API endpoints all returned errors. This is the largest annotated lateral set in existence and its absence is the single biggest gap in the corpus.
  • BUU — 77 of ~7,200 files. Google Drive caps folder downloads; the rest needs per-file IDs or rclone.
  • CM Spine — Google Drive refused the transfer. This is the only public intraoperative source, so no fluoroscopy is represented and the ±180° C-arm rotation policy is untested.
  • AASCE — SpineWeb request form. Its absence means no thoracic levels and no AP full-spine anywhere in the corpus.

Built but not exercised

  • Ignore-region loss mask — geometry and rendering are implemented and unit-tested; the ultralytics loss patch is not wired in, so the headline ablation is unrun.
  • Level head — not started. The spec is explicit that detection must be stable first, and it is only now stable.
  • Per-acquisition augmentation — the policy is specified; the C-arm case has no data to apply it to.
  • Annotation programme — CVAT, honeypots, adjudication: needs people, and needs the credentialed datasets above.
Read the headline numbers accordingly. 0.957 AP@50 is an in-distribution result on three lateral-dominant sources with cropping instead of ignore masks. It demonstrates the pipeline is correct end to end. It is not evidence of cross-site generalization, which is the property the project exists to establish.

Reproduce

python -m src.build_dataset          # converters -> normalised PNG + manifest
python -m src.export_yolo            # manifest -> ultralytics pose format
python -m src.train --epochs 120     # fliplr=0.0, mosaic=0.0
python -m src.run_eval --weights runs/pose/runs/detect_v1/weights/best.pt

25 unit tests cover the manifest schema and the corner geometry — slot ordering is rotation- and winding-invariant, self-intersecting quadrilaterals are rejected, and a level may not be recorded without recording how it was known.
