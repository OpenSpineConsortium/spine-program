Elsevier's text and data mining grant for WSU, and the terms the institutional token carries.

- Granted: Scopus and ScienceDirect text and data mining, text, images and multimedia (Greg, 2026-10-18: "they gave
  me sciencedirect and scopus preemptively"). Elsevier's data support wrote on 2026-10-16 that it would update the API
  key's configuration once the ScienceDirect amendment is finalized, so the key's ScienceDirect access is checked by a
  first harvest job (E5.2) before it is relied on.
- The institutional token's terms (Elsevier, 2026-10-16): kept server-side in a password-protected environment, never
  in browser code or the address bar; full access to WSU's account; revocable without notice; HTTPS only; the key in
  the header X-ELS-APIKey and the token in X-ELS-Insttoken. Its value is in no file of this repository.
- What WSU told Elsevier on 2026-10-15 (`../01_carm_level_detection/grants/aidas_2027/RECORD.md` section 6): no
  Elsevier content trains or improves any model or reaches an outside AI service; everything on the grid in
  access-controlled storage; only brief quotations with citation and DOI published; the index and full text deleted
  when the project ends or the key lapses.
