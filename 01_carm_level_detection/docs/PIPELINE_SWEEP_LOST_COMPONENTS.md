### 6.3 The rule

One rule would have caught every row in 6.2:

> **A run records what it resolved, not what it was asked for; and a value it could not resolve is an
> error, not a default.**

Four checks make it enforceable, and each is greppable:

| Check | Greppable invariant |
|---|---|
| a. No filename built from a literal component that a flag also controls | any string literal matching `rung_\d`, `_k\d`, or a bare `.pt`/`.npz` name inside a path join |
| b. A path the caller named must raise when missing; a default path may be skipped, but the skip is written into the artefact, not only to stdout | every `if <path> and Path(<path>).exists():` with no `else` |
| c. Every artefact records the resolved path and the sha256 of every weight file loaded. `"x": a.x` in a meta dict is a bug whenever `x` is also resolved elsewhere in the same function | `"\w+": a\.\w+` inside a `meta`/`rep`/`report` dict literal |
| d. `argparse` carries `choices=` wherever a consumer enumerates values, and an unhandled value raises instead of selecting nothing | any `if a.X == k: ... elif a.X == j:` with no trailing `else: raise` |
| e. A pairing between two weight files is checked by content hash, not by name, directory or tensor width | any `load_state_dict` whose file was chosen by an f-string |

`tools/fluorocap_infer_v2.py:116-142` already implements (c) and (e): it hashes every weight file it
loads and names its head `recurrent_head_<bank>_<sha8>_r<rung>.pt`. That file is the template; nine
other tools and `service/` are not written that way.

A cheap enforcement that needs no refactor: one preflight that imports each entry point, resolves
every default with no arguments, and prints the resolved path, its existence and its sha256. Run it
in CI and in the first line of each chain. Every row in 6.2 shows up as a missing file, a stale sha or
a literal that does not match the bank in `--ctx`.
