# RSNA AI manuscript — the endpoint of the k-devices work, as a verified checklist

Greg's directive (2026-09-22 ~08:50 EDT): a concise *Radiology: Artificial Intelligence* paper is the culmination of
this work. Every box below is ticked ONLY when the evidence named beside it exists on disk, was produced by the
named script with a recorded seed and code SHA, and passed the named verification. "Status" lines carry the date
of the last real check and what was actually observed — never a guess. Re-verify a box before quoting it.

Rules of accountability (apply to every box):
- **Data:** every dataset in the paper is listed in `docs/RSNAI_DATA_MANIFEST.json` with source URL/DOI, licence,
  download date, file count, total bytes and a SHA-256 over the file list; splits are by case and stored as JSON;
  no test case of any device appears in any training list (`tools/or_audit_splits.py`, `or_audit_dupes.py`).
- **Reproducibility:** every number in a table comes from a JSON written by a script under `tools/`, with `seed`,
  `code_sha` and input paths inside the JSON; the SLURM job file that produced it is under `slurm/`. A claims
  ledger `docs/RSNAI_CLAIMS.json` keys each manuscript number to its JSON path; `tools/claims_check.py` re-derives
  each number and exits non-zero if one moved (pattern of `make physics`).
- **Statistics:** uncertainty is a case-level bootstrap 95 % CI (frames of one subject are one cluster); a
  comparison between arms is a paired bootstrap on the same frames; a "beats" claim needs the CI of the difference
  to exclude zero. Pre-stated pass criteria are written in the box BEFORE the experiment is read.
- **Device hold-out means device:** a number called "held out" has that device absent from training frames,
  training renders' poses, AND the calibration terms of the initialisation (the init-exposure trap of 2026-09-22).
