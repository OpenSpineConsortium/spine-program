# Topic 1: the bibliography of the cross-reference (every prior research report, sweep, prior-art note and dataset review on disk)

Compiled 2026-10-08 from files on disk only (no network). This is the list the later topics cite. It records what each file asked, which datasets and studies it names with the n it records, what it concluded, and whether it was verified. It does not re-verify anything.

## How to read this note

**Roots.** `S/` = `spinesurg-ct-nnunet:`. `C/` = `CTSpinoPelvic1K:`. `M/` = `memory:`.

**Citation rule.** Each row's File column is the source of every cell in that row. Every n, result and conclusion in a row is "as recorded in" that file, unless a cell names another file. Where a number in a row comes from somewhere else, the cell names that file.

**Date column.** "stated" means the date is written in the file or its name. "mtime" means the file's modification time on disk. "git" means the first and last commit dates from `git log` in the CTSpinoPelvic1K repository. "modified" means the `modified:` field of a memory note.

**Verified column.** The labels are:
- *Voted*: a deep-research harness put each claim to three adversarial verifiers. The counts are claims extracted / verified / confirmed / refuted, as the file's own `stats` block records them.
- *Read from source*: the file says its numbers were read from the primary text. No vote is recorded.
- *Identifiers checked*: DOIs and PMIDs were resolved. Numbers were read from an abstract or a full text, as marked per claim.
- *Unverified*: the file says so, or nothing about verification is recorded.
- *Not a review*: a plan, specification, datasheet or own-result note, kept because the task lists it.
- *AI-generated*: a synthesis produced by an outside AI tool, with no verification recorded.

**Scope.** Section A covers `S/reports` and `S/research_notes`. Section B covers `S/docs/research_*`. Section C covers the prior-art and dataset documents listed in `S/docs`. Section D covers `C/docs` and the dataset article. Section E covers the memory notes the task listed. Section F covers the PDFs named for datasets or reviews; most of them sit in `C/`, not on the Desktop root. Section G covers literature and dataset reviews found outside the listed folders, which the cross-reference should not miss. Section H lists files that were considered and left out, with the reason. Section I collects the places where two files record different n for the same dataset. Section J is the unknowns table.

Row count: 114 rows in sections A to G (A 15, B 15, C 16, D 9, E 19, F 16, G 24).
