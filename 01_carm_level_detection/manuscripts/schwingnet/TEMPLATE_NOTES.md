# Template notes

The tree follows the cai4cai/RSNATemplate skeleton (main.tex, rsnastyle.tex, nejm.bbx, nejm.cbx, latexmkrc,
a .bib). The template files were reproduced from memory of that repository on 2026-09-22; nothing was fetched.
Where a line could not be recalled with confidence, a working minimal equivalent was written and is listed
here so a reviewer can swap in the originals.

## rsnastyle.tex

Faithful to the template as recalled: `article` 11 pt; `fontspec` with Times New Roman (so xelatex or
lualatex); `lwarp`; `geometry` A4 with 2.5 cm sides and 3 cm top/bottom; `setspace` double spacing; `biblatex`
with `style=nejm`, `natbib=true`, a `simplebib` enumerated environment; `endfloat` with `tablesfirst` and
`nomarkers`; `tocloft`; `authblk`; `parskip`; `glossaries` with the `acronym` option.

Departures, each guarded so the same main.tex compiles on a full TeX Live and on the compute grid. The grid's
compute nodes carry TeX Live 2013 in `/usr/bin` (no xelatex, no biblatex) and a `texlive/2020` environment
module (xelatex, latexmk, biber, biblatex, endfloat, lwarp, glossaries all present; Times New Roman absent);
`slurm/compile.sh` loads the module, so on the grid the biblatex branch is the one that runs. The fallbacks
below remain for a TeX install without those packages:

| template | here | why |
|---|---|---|
| `\setmainfont{Times New Roman}` | `\InputIfFileExists{localfont.tex}{}{\setmainfont{Times New Roman}}` | the grid build writes `localfont.tex` = `\setmainfont{TeX Gyre Termes}` (the Times clone that ships inside TeX Live; Times New Roman is absent on the grid) |
| `\usepackage{lwarp}` | loaded only if a marker file `lwarp-enable.tex` exists beside main.tex | HTML export hook; in the PDF build it rewrote the glossaries output and wrote seven css/xdy/ist side files, so it is opt-in |
| `biblatex` + `biber`, `\printbibliography[env=simplebib]` | loaded when `biblatex.sty` exists; otherwise `natbib` numeric with `unsrtnat` and bibtex; main.tex calls `\rsnabibliography`, defined in both branches | the grid has no biblatex |
| `endfloat` | loaded only if present | on the grid the floats stay at their positions (the end of the document, where main.tex places them) |
| `\makeglossaries` + `\printglossary` (needs the `makeglossaries` script via latexmkrc) and `\newacronym` | `\rsnaacronym{key}{ABBR}{expansion}` registers the acronym with glossaries (so `\gls` still works) and appends it to a plain list that `\printabbreviations` prints | with TeX Live 2020's glossaries 4.46 the `\printnoidxglossary` list came out empty in this document even after four passes, so the printed list no longer depends on the glossary machinery; no external program is needed |
| `\newcommand{\ci}` etc. | added | the template does not define number helpers |

Packages added beyond the template: graphicx, booktabs, array, amsmath, xcolor, caption, hyperref (hidelinks).

## nejm.bbx and nejm.cbx

The template ships its own nejm style files. They were not copied verbatim; the versions here are minimal
equivalents built on `numeric-comp`: surname then initials, up to six authors then "et al", article titles
without quotes, journal abbreviation, `year;volume(issue):pages`, doi printed, numeric citations in
parentheses in order of first citation. If the originals are available they can replace these two files
without touching main.tex.

## latexmkrc

`$pdf_mode = 5` (xelatex), `$bibtex_use = 2`, and the `makeglossaries` custom dependency the template uses.
Because rsnastyle.tex uses the noidx glossary, the custom dependency is inert here and harmless.

## main.tex skeleton

Follows the template order: `\title`/`\author`/`\affil`/`\maketitle`; **Article type**; **Summary statement**;
**Key results** (three items); `\newacronym` lines and **List of abbreviations**; `\clearpage`; `\section*{Abstract}`
with Purpose / Materials and Methods / Results / Conclusion (the template's "Background" and "Conclusions" labels
are replaced by the journal's four headings); `\clearpage`; Introduction; Materials and Methods; Results;
Discussion; Other information (the journal's required statements); bibliography; `\clearpage`; **Figure
Legend(s)** via `\@starttoc{lof}`; then the figures and the four tables. Figures use
`\begin{figure}[tbh!]\centering\includegraphics...\caption{...\label{}}\end{figure}` as in the template.

## Fonts on the grid

The module's fontspec does not see the system's Liberation Serif and Times New Roman is absent, so
`localfont.tex` (written by `slurm/compile.sh`, not committed) selects TeX Gyre Termes from TeX Live's own
font tree. Delete it (or leave it absent) to get Times New Roman on a machine that has it.
