## Building

```sh
python make_figures_mbr.py     # writes Figure1/2_MBR .pdf .eps .tif
python make_supplementary.py   # writes ESM_1.xlsx
./build.sh                     # compiles manuscript, cover letter and ESM_2
```

`build.sh` uses [Tectonic](https://tectonic-typesetting.github.io/), a single-binary
LaTeX engine that fetches the packages it needs on first run. It downloads the
binary into `.build/` if it is not already there, so no system-wide TeX install is
required. If you would rather use MiKTeX or TeX Live, `pdflatex sn-article.tex`
twice works identically — everything the class needs is in this directory.

## Supplementary material

Springer wants spreadsheets as `.xlsx`, named consecutively (`ESM_1.xlsx`), cited
in the running text as "Online Resource 1", captioned in the manuscript, and
carrying the article title, journal, authors and corresponding author's e-mail
inside the file — SI is published exactly as received, with no editing. All of
that is in place. The sheet list follows the convention in comparable
transcriptome-to-drug-repurposing papers (samples → full DE → significant DE →
enrichment → network → drugs):

| Sheet | |
|---|---|
| S1 | every sequenced library: rat, laboratory label, treatment, tissue, RIN, human read share, role |
| S2 | DESeq2 result for every gene tested (19,351) |
| S3 | the 35 differentially expressed genes, with gene name, locus class and network membership |
| S4 | how the DE count moves with the fold-change threshold |
| S5 | complete GSEA result, all 8,869 gene sets |
| S6 | the six gene sets at FDR q < 0.25 |
| S7 | subtype scores by arm, with the limma test |
| S8 | subtype scores per sample |
| S9 | STRING identifier mapping |
| S10 | STRING edges (one row per interaction) |
| S11 | network genes ranked by degree |
| S12 | full DSigDB ranking with ChEMBL properties (100) |
| S13 | top 20 unique compounds by Integrated Score |

Class options are `[pdflatex,sn-basic,Numbered]`: Springer Basic reference style
with numeric square-bracket citations, which is what MBR asks for. Dropping
`Numbered` switches natbib to author–year and the manual `thebibliography` will
fail with "Bibliography not compatible with author-year citations".

## Figures

Both are drawn at 174 mm (Springer text width) so they are placed at 1:1 and no
type is reduced. Springer asks for lettering "usually about 2–3 mm (8–12 pt)" in
Arial or Helvetica at final size, so nothing in either figure is below **7.5 pt**
and axis labels are 8 pt. TIFFs are 600 dpi (Springer's minimum for combination
art); EPS is supplied for the vector route. Colour is requested online only —
both figures stay readable in greyscale, because the one two-group panel also
separates by marker shape and direct labels, and no caption refers to colour.
Every value comes from `../manuscript/Supplementary_Data.xlsx` or
`../SLIDES/figures/facts.json` — nothing is typed into the figure code.
