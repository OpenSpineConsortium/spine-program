## What this is

The Open Spine Consortium's public site, https://openspineconsortium.com, is a static site generated by one script in
the repository `OpenSpineConsortium/openspineconsortium.github.io` and published by GitHub Pages from `master`. It
carries the consortium's research, data and people pages, the onboarding and Beethoven pages that bring medical students
onto the grid, six workshop tutorials, a per-level morphometry atlas, and a PACS-style demo: a NiiVue CT viewer on
CTSpinoPelvic1K case 0003 that animates the spinopelvic constructions the toolkit computed, and an X-ray tab that sends a
film to a hosted level service and draws the corners and level names it returns. This folder holds what a maintainer
needs that is not in a repository: the consortium mark and its generator, the medical-education visual abstract and
its build scripts, the eight student-readable handoff files, 27 memory notes, and the four manifests that say where
everything else is.

## Goal

Keep the site correct and publishable: every page a body fragment built by `tools/build_site.py`; the demo consuming
`metrics.json` from the toolkit's exporter; the X-ray tab pointed at a live service or at nothing; the atlas equal to the
release's morphometry at a named commit; the tutorials, onboarding and data pages saying v11 and never instructing work
on the login node; no weight and no radiograph ever in the tree. The one decision this project cannot make, where the
level service is hosted, is `01_carm_level_detection` step S2 and is Greg's.

## How to start

Open the clone's top folder (the root of `spine-program`), never this folder, as the Claude Code project or as a
Project's repository; this folder is the project when the claimed issue's title names it (the root `README.md`,
"Choosing a project"). Before the first change read `CLAUDE.md`, then this file, `DATA.md`, `TODO.md`, `STATUS.md` and
`MANIFEST_GRID.md`. Work starts from the claimed issue's acceptance lines, not from `TODO.md` step 1; a TODO step with no
issue gets a todo issue, which Greg opens, before work starts. The site lives in another repository: clone it
(`MANIFEST_CODE.md` section 1), run `git pull`, then `python -X utf8 tools/build_site.py --check-only`. A change to it, or
to any other repository, lands as `12_website_pacs_demo/patches/<N>-<slug>.patch` in the claim's pull request.
