We thank the reviewer and respond to each point in order.

(1) Completeness. Closed: every shipped case carries a dense, fully-fused spine+pelvis labelmap, no disjoint masks, no ignore voxels. Crucially, the structures where wrong-level error originates - lumbar counting, the L5/L6-vs-sacrum call, and vertebra class-mixing - are CTSpine1K radiologists' vertebral ground truth, never model output: we never pseudolabel a vertebra. Completion is confined to the pelvis (sacrum, ilia) on scans lacking it, large high-contrast bone where counting error does not arise, so it cannot add a miscount or class-mix (any residual class-mixing is inherited from the source masks, a known CNN artifact, not introduced). We trained nnU-Net v2 (5-fold CV, ignore-label protocol) and filled each missing pelvis out-of-fold (no train-on-test leak). We retain the last rib-bearing vertebra (above ground-truth L1) as a counting anchor that, with the sacrum, makes L1-L6 numbering deterministic. For camera-ready we will report leak-safe out-of-fold Dice of the pelvic pseudolabels against CTPelvic1K's separate pelvic-only ground truth - the only model-generated part.

(2) Training pipeline (abstract vs Section 9). The pipeline is complete (nnU-Net v2, ResEnc planner, 3d_fullres; it produced the v2 completion above), and all code and the 5-fold checkpoints are public now, reachable from the dataset README. We will reconcile the abstract/Section 9 wording; only the trained-baseline evaluation remains, for the revision.
