We thank the reviewer for the detailed, constructive review and respond in order.

(1) Trained baseline and ablation. We agree this is the key gap. The nnU-Net v2 model is trained (5-fold cross-validation under the ignore-label protocol; it generated the out-of-fold completion described below). All code and the 5-fold checkpoints are released now, reachable from the dataset README cited in the paper; the trained-baseline evaluation on the fused test split and the fused-only versus all-cases ablation follow at camera-ready.

(2) Count reconciliation. An authoritative accounting table, regenerated from the manifest, is in the dataset README (main and v2 branches); it reconciles patients, series, masks, volumes, region annotated, splits, and LSTV at each granularity. The apparent contradictions are masks vs volumes vs placed cases: 1,498 placed masks (784 spine + 714 pelvic) over 825 cohort patients reduce to 1,153 exported volumes across 802 matched patients (342 fused, 440 spine-only, 371 pelvic-only; train/val/test 805/174/174); LSTV totals 53. The abstract (1,137) and Table 3 (1,163; 54 LSTV) used stale placement runs; the manuscript will adopt the README table verbatim.

(3) LSTV labels are not merely inherited heuristics. Our radiologists have independently Castellvi-classified all LSTV cases (33 patients, 53 LSTV volumes - a separate-mode patient is two scans), including the ambiguous cross-source-disagreement cases, recording the transitional type, left/right laterality (e.g. type IV: IIa right, IIIa left), and the non-rib-bearing vertebra count, with per-case notes. This clinical read defines the LSTV phenotype alongside the original labels kept from each source dataset; we release it as a phenotype table on the dataset branches and report it as a subset audit, and will extend the read to any remaining cases on request. These two LSTV calls are independent (count from CTSpine1K, pelvic flag from CTPelvic1K; 25 of 33 vertebral-source, 8 pelvic). The fidelity-critical lumbar counting and class-mixing are radiologist ground truth, never pseudolabelled - only the pelvis is model-completed, with camera-ready Dice vs CTPelvic1K's pelvic-only ground truth.

(4) TotalSegmentator metrics. Per-class Dice (Table 5) is computed on the 272 fused cases only, which have complete ground truth. The subgroup junction metrics (Table 6, over 921 cases) are scored per case only against the labels it actually has: a per-config mask scores L1-L6 for spine-only and sacrum/hips for pelvic-only cases (all nine for fused), the junction DSC and error rate count voxels only where ground truth exists, and cases lacking both L5 and sacrum in the ground truth are excluded. No metric is ever scored against an unobserved region; this scoring code is in the released repository.

(5) Wording and release. We will temper "most widely deployed ... in production clinical use" to a citation-backed claim. The dataset, code, and checkpoints are public now.
