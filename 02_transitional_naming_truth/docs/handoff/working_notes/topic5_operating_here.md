## 7. OpenSpineToolkit (`ostk`)

- What it is: a tested Python package of shared geometry primitives and measurements (PI/SS/PT, lumbar lordosis,
  PI-LL + SRS-Schwab modifiers, coronal Cobb, per-level morphometry, six-point vertebral morphometry) plus
  `projects/<name>/` student miniprojects. Modules: `labels, io, geometry, masks, spine, metrics, metrics2d, cobb,
  morphometry, vertebral_body, genant, drr, project2d, surgery, record, parallel, cli`. CLI:
  `python -m ostk {pi,ll,cobb,all,morph} --labels <dir> --out <file> --workers 8`; `python -m pytest`. All geometry
  in world millimetres via the affine; the sagittal plane comes from the femoral-head axis; bad cases return
  `value=None` + `qc_flags`, never an exception (`ostk-repo/CLAUDE.md`; `ls ostk-repo/ostk`).
- `SPEC.md` is the technical contract (`ostk-repo/CLAUDE.md`).
- **The two label schemes trap.** Release v10/v11 (VerSe-native): C1-C7 = 1-7, T1-T12 = 8-19, L1-L6 = 20-25, sacrum
  26, coccyx 27, T13 28, (S1 29 in v10 only), hips 30/31, femurs 32/33, ribs 34-59, lumbar ribs 60/61, hardware
  62-68. Legacy ostk / PACS demo: L1 = 1, S1 = 7, sacrum 8, hips 9/10, femurs 11/12. Mixing them does not raise:
  "femur_left" comes back T4. Call `ostk.labels.labels_for(volume)` (detects by pelvis voxel mass, **raises
  `SchemeError`** when ambiguous); `lid(name)` without a volume is "the thing to avoid in new code"
  (`ostk-repo/ostk/labels.py` docstring; mem:label-scheme-v4-vs-ostk.md; mem:scheme-bone-hardware-only.md;
  `ctsp/CLAUDE.md`).
- **Id 29 is retired in v11** (dissolved into 26); code that gates on 29 must go with it (`ctsp/CLAUDE.md`;
  mem:s1-carve-changed-spinopelvic.md). Students keep v10 identifier text until v11 ships on HF and Zenodo
  (mem:hf-mirror-is-v10.md lists the exact lines to change then).
- **Open defect:** commit 1b7005c (2026-09-10) ring closing inflates posterior body height / end-plate depth by
  10-17 mm on about 1 in 7 vertebrae with no gate firing; `canal_mask min_vox=20` admits 3 mm "canals". Do not trust
  `level_morphometry` VBHp / EPD / EPWl computed after 2026-09-10 22:52 until fixed; the release CSV (commit 90a27a7)
  predates it. The local clone's history after 1b7005c (ba82e1a 2026-09-11, cb43197 2026-09-25) carries no fix
  (mem:ostk-canal-closing-regression.md; `git log` 2026-10-08).
- Volumes are stored ('P','I','R'): canonicalise to analyse, never to write; read directions with
  `nib.aff2axcodes` (mem:ct-volumes-are-pir-not-ras.md; mem:never-reorient-when-writing-labels.md).
- PACS demo (`openspineconsortium.github.io/pacs/`) is driven by `pacs/data/<case>/metrics.json` from
  `ostk-repo/tools/export_demo_case.py` (mem:pacs-demo-and-ostk-params.md).
