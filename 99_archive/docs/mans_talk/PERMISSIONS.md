# Figure permissions — Reading Spine MRI

23 figures are live on `openspineconsortium.com/spine-mri/` marked *permission pending*,
from **7 papers** across **4 publishers**. Four of the seven are the same publisher, so
this is **four requests**.

All four publishers run permissions through **RightsLink** (Copyright Clearance Center).
You will need one free CCC account — make it once on the first request and reuse it.

---

## Fill the form the same way every time

RightsLink asks the same questions whichever publisher you came from. These are the
answers for this project. **Read the two marked ⚠ before you start.**

| Field | Answer |
|---|---|
| I would like to… | **Reuse in a website** (if absent: *Republish in another publication* → medium **website**) |
| Requestor type | **Academic / educational institution** (or *Non-profit* if offered) |
| Are you the author of this article? | **No** — you are not an author on any of these seven |
| Format | **Electronic** ⚠ *website use always needs the electronic licence; print-only will be the wrong licence* |
| Portion | **Figures / tables / illustrations** |
| Number of figures | per the table below — count panels, not figure numbers |
| Will you be translating? | **No** |
| ⚠ Are you modifying the content? | **Yes** — see note below |
| Distribution | **Worldwide** |
| Circulation / audience | a realistic estimate; a few hundred to a few thousand is honest for a talk companion |
| Duration of use | **Life of current edition** / permanent |
| Title of your new work | *Reading Spine MRI — an open teaching series* |
| Publisher of new work | **OpenSpineConsortium** |
| Will it be sold / behind a paywall? | **No** |
| URL where it will appear | `https://openspineconsortium.com/spine-mri/` |

**⚠ Answer "yes" to modifying the content.** Almost none of these are straight
reproductions — multi-panel figures were **cropped to single panels**, and the Lee figure
is an **assembly of ten panels from six figures into one new image**. Some publishers
price or route a derivative differently. Declaring it costs nothing; being found to have
under-declared it is the expensive version.

If a free text box appears, this is the description that helps most:

> Free, openly accessible online educational series for advanced practice providers and
> trainees. Non-commercial, no paywall, no advertising. Full citation and a link to the
> original article appear in the caption of every figure.

## If something is refused or priced

- **Bednarik, Kato, Nouri, Arvin** — single supporting panels. Drop them; the surrounding
  text carries the argument.
- **Pfirrmann** — Part 3 §2 is built on all four grades. Replacing them means shooting the
  equivalent from your own PACS. A real afternoon, but doable.
- **Schizas** — the hard one. Part 2 depends on it end to end: the reference chart, the
  66 mm² case, the overlap plot, the drill. There is no open-licence substitute for that
  grading figure. If refused, Part 2 becomes text plus your own cases.

originals, which would genuinely improve the site: everything currently live was extracted
from PDFs at publication resolution, and the Lee panels had to be re-rendered from the page
because the embedded image streams came out inverted.

Say the word and I will draft those into your Outlook **Drafts** folder for you to review
and send. Outlook is already set up for this on your machine — no credentials, no
